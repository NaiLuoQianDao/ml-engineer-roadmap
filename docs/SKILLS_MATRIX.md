## Engineering tools: required mastery vs reference usage

- **Use independently:** common `git status/add/commit/push`; basic Python execution and reading simple pytest PASS/FAIL reports.
- **Understand and adapt:** `git diff --cached`, `uv run --with pytest`, `python -m pytest <path> -v`, `test_*` naming and imports.
- **Look up before using; no memorization requirement:** `git rm -r --cached`, `git check-ignore -v --no-index`, `uv --index-url`, and future branch/PR commands.
- For new daily learning tasks, supply only the **most necessary external reference**, and keep the student's own code and verifiable tests central.

## Verification rubric

- **Introduced** — encountered in lecture/explanation.
- **Understood** — can explain purpose and behavior in own words.
- **Independent** — can solve a new variation without copying.
- **Verified** — source and test outputs inspected, including relevant edge cases.
