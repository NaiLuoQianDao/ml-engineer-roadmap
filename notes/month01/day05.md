# Day 5 — Python Lists & Tuples

**Date:** 2026-10-11

## 1. What I Learned
Today I mainly studied Python's core sequence structures: List and Tuple.
今天主要学习了 Python 的核心序列结构：List（列表）和 Tuple（元组）。

A List is represented with [], is mutable, and is suitable for frequent additions, deletions, and modifications.
List 用 [] 表示，是可变（Mutable）的，适合频繁增删改。

A Tuple is represented with (), is immutable, and is suitable for protecting fixed data.
Tuple 用 () 表示，是不可变（Immutable）的，适合保护固定数据。

When accessing data, you can locate a single element through an Index, which starts from 0 and supports negative numbers.
访问数据时，可以通过 Index（索引，从 0 开始，支持负数）定位单个元素。

Or you can extract a subsequence in batches through Slicing, written as [start:stop:step], including the start but excluding the stop.
或者通过 Slicing（切片，[start:stop:step]，包头不包尾）批量提取子序列。

In addition, I also mastered List Methods, such as append, pop, and sort, to implement data addition, deletion, modification, and querying.
此外，还掌握了 List Methods（如 append、pop、sort 等）来实现数据的增删改查。

Understanding the difference between mutable and immutable is the core key to mastering these data structures today.
理解可变与不可变的区别，是今天掌握这些数据结构的核心关键。
